# Derrick Mullins’ Portfolio

A personal website and portfolio built with React and Material UI, hosted on GitHub Pages.

## 🌐 Live Demo
Check out the live site here: [https://derrick-mullins.com](https://derrick-mullins.com)

## 🚀 Tech Stack
- **Frontend**: React 18
- **UI & Styling**: Material UI (MUI) & Emotion
- **Routing**: React Router 7
- **Deployment**: GitHub Pages

### Prerequisites
- **Node.js**: v14.0.0 or higher
- **npm**: (comes with Node.js)
